# Purdue Competitive Analysis — Open Knowledge Format Bundle

Two bundles under this root, both conforming to [OKF v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md):

- [`project/`](/okf/project/index.md) — what this repo is and how its pieces fit together:
  the web app, `field_pipeline`, `knowledge_base`, and the browser-harness core they run on.
  Hand-written, changes only when the system changes.
- [`knowledge/`](/okf/knowledge/index.md) — the actual competitive-analysis findings: one
  concept per (program, field group), with every value's source URL and quote. Generated by
  `python -m knowledge_base` (see [`okf_export.md`](/okf/project/components/knowledge-base.md));
  not checked into git — rebuild it to regenerate, or open the web app's **Knowledge** page.
